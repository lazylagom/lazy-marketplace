# Lazy Marketplace

> Stay Lazy, Act Crazy

A curated Claude Code plugin marketplace for developers who want to work smarter, not harder.

## Quick Start

### 1. Add the Marketplace

- In Claude Code, run:
  
```bash
/plugin marketplace add lazylagom/lazy-marketplace
```

### 2. Install a Plugin

- In Claude Code, run:
 
```bash
/plugin install <plugin-name>
```
